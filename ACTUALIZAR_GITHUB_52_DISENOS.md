# Actualizar GitHub Pages con los 52 diseños nuevos

## Opción recomendada: actualización rápida sin borrar tus contactos

Usa el paquete `NebuLabs_Actualizacion_GitHub_52_Disenos.zip`.

Este paquete **no contiene `assets/js/config.js`**, por lo que conserva el número de WhatsApp, Instagram y correo que ya configuraste.

Reemplaza o agrega estos archivos y carpetas manteniendo la misma estructura:

```text
index.html
assets/js/catalogo.js
assets/js/app.js
assets/images/productos/  (52 imágenes nuevas)
ACTUALIZAR_CATALOGO.md
LISTADO_52_DISENOS_AGREGADOS.md
```

Después confirma los cambios con un mensaje como:

```text
Actualización catálogo: 52 diseños nuevos
```

## Opción completa: reemplazar todo el repositorio

1. Descarga y descomprime `NebuLabs_Repositorio_Actualizado_86_Productos.zip`.
2. Antes de subirlo, abre tu archivo actual `assets/js/config.js` y copia tu WhatsApp, Instagram y correo.
3. Pega esos tres datos en el nuevo `assets/js/config.js`.
4. Sube el contenido completo, dejando `index.html` en la raíz del repositorio.

## Verificación final

- Abre la página publicada.
- Busca `Pulpo esqueleto`, `Ajedrez galáctico`, `Stitch` o `Pato Hulk`.
- Comprueba que las medidas estimadas tengan el símbolo `~`.
- Comprueba que los diseños sin precio muestren `Cotizar`.
- Prueba el botón de WhatsApp.
- Si no ves los cambios, recarga con `Ctrl + F5` o abre una ventana de incógnito.
