Preguntas frecuentes

Todo claro antes de imprimir.

Los tiempos, colores y valores se confirman antes de iniciar la fabricación.

¿Los precios pueden cambiar?

Sí. El valor puede variar si cambia el tamaño, el número de colores, el acabado, la complejidad o la cantidad solicitada.

¿El precio corresponde a una unidad?

Sí. Cada diseño se vende por unidad, incluso cuando la fotografía muestre varios colores o modelos. Solo se cotiza como conjunto cuando el producto se identifica expresamente como juego, set o promoción.

¿Puedo escoger el color?

Sí. Se confirma la disponibilidad del material antes de iniciar la impresión.

¿Se pueden fabricar tamaños diferentes?

Sí. Se puede cotizar otra escala según el modelo y la viabilidad de impresión.

¿Cuánto tarda un pedido?

El tiempo depende del tamaño, nivel de detalle, cantidad de piezas y carga de producción. Se informa en la cotización.

¿Cómo se realiza el pago?

Transferencia bancaria o efectivo.
