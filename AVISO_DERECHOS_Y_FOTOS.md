# Aviso sobre derechos de diseños, personajes y fotografías

Este paquete fue construido con el material suministrado para el proyecto y utiliza una selección de imágenes optimizadas para mostrar el catálogo.

Antes de monetizar públicamente una referencia, verifica:

1. Que el archivo STL o modelo 3D permita uso comercial.
2. Que la licencia no sea exclusivamente personal o no comercial.
3. Que tengas autorización para usar fotografías de terceros.
4. Que los personajes, nombres, logotipos o franquicias se utilicen conforme a los derechos aplicables.
5. Que no se presente una fotografía de referencia como si fuera una producción propia cuando todavía no lo sea.

## Recomendación comercial

A medida que imprimas tus productos, reemplaza las imágenes de referencia por fotografías propias de NebuLabs Studio J.D 3D. Esto mejora la confianza del cliente, fortalece la identidad de la marca y reduce riesgos de uso de material de terceros.
